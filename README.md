# Vase Emergency — Shardstorm

A 3D tabletop puzzle for friends. Every piece is a curved, thick ceramic patch cut from the vase's lathed surface; the jagged neighboring borders are built to fit each other in 3D. Drag shards around the vessel, rotate them, orbit the camera, and assemble the shell with no ghost vase, target slots, or suggested pieces. Connected fragments move as one, and the finished object is the vase itself.

## Play
Open the [GitHub Pages game](https://moai-heads.github.io/vase-emergency/) or serve this folder over HTTP.

- Drag a shard or connected cluster with the left mouse button.
- Press **Q / E** to rotate the selected shard or cluster by 90°.
- Right-drag to orbit the 3D camera; use the wheel to zoom.
- Choose 10, 50, 100, 200, 500, or 1,000 real vase fragments.

The Three.js runtime is vendored locally, so gameplay does not depend on a third-party CDN.
